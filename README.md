## 1️⃣ Sales Analysis Dashboard

A **Tableau-based sales performance dashboard** analyzing revenue, profit, units sold, and geographic distribution across products, categories, and sales representatives.

**Data Sources:** `Sales Data.csv`, `Product.csv`, `Categories.xlsx`, `SubCategories.xlsx`, `Geography.xlsx`, `SalesRep.xlsx`

**Key Metrics:**
- Total Revenue & Profit
- Units Sold by Product & Category
- Geographic Sales Performance (Country & Town)
- Sales Representative Performance
- Revenue Discount Analysis

📁 **Files:** `Book1.twb` + supporting CSV/Excel data files

## 🚀 How to Use

1. Install **Tableau Desktop** on your machine.
2. Clone or download this repository.
3. Open the `.twb` file of any project in Tableau Desktop.
4. Ensure all supporting data files are in the **same folder** as the `.twb` file.
5. If prompted, re-map the data source paths to your local folder.
